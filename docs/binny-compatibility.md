## Reproduce the probe

From the repository root:

```sh
deps/nim-devel/bin/nim r tools/binny_phase0.nim
deps/nim-devel/bin/nim r tools/binny_phase0.nim --build
```

The first command reports compiler version, `--genBif` support, and `nifler`
availability. By default it selects `deps/nim-devel/bin/nim` when that
project-local compiler is present. The second attempts the documented
native-artifact style command against `tests/fixtures/binny_phase0/main.nim`
and safely summarizes every `.s.bif` found in the temporary Nim cache. Both
commands fail clearly when the required compiler capability is unavailable;
there is no language-backend fallback.

## Fixture coverage

`tests/fixtures/binny_phase0/` contains:

- an imported module;
- public and private records and routines;
- overloads and a generic routine;
- a macro and a nested local helper;
- Unicode source text;
- a long source-line marker for position/range experiments.

The project-local Nim devel compiler provides `--genBif` and the companion
`nifler` tool. Synthetic BIFs cover malformed-input and ownership-boundary
cases; the real fixture command is the evidence required before enabling
source-semantic LSP capabilities.
